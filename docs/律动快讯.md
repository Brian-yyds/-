# 律动中文快讯

使用[官方文档](https://www.theblockbeats.info/apiDoc)的Pro HTTPS接口 `https://api-pro.theblockbeats.info/v1/newsflash`，密钥仅放在`api-key`请求头，不放URL。参数`page=1,size=50,lang=cn`，不限制分类。每5分钟抓取一次；浏览器不直接访问API，行情刷新和动画不消耗额度。

## 密钥与运行

Windows通过当前用户DPAPI加密保存到`user_data/api_keys.blockbeats.dpapi`；其他机器使用`BLOCKBEATS_API_KEY`环境变量。密钥不回显，不进入源码、GitHub、快讯HTML或同步数据包。可在设置页“数据与AI接口”更新。环境变量优先于本机保存值。新系统不配置Key时快讯等待配置，其他监控继续工作。

`launch.py start`增加独立`blockbeats_monitor.py`子服务，共六个主服务，桌面快捷方式不变。重启尊重上次持久保存的下一次采集时间，避免重启反复消耗额度。普通错误至少等5分钟；鉴权/套餐错误等30分钟，429尊重较长的Retry-After。失败保留缓存，界面标为重试或过期，不把旧快讯说成新抓取。

首次读取最新50条。以后以快讯ID去重并更新修订正文；离线期间超过一页时最多追三页/150条，到上限显示覆盖可能有缺口。缓存保留最近两天观测到的最多500条，显示并导出最新100条。不会声称补齐无限离线历史。发布时间保留API原始字符串，无时区日期按北京时间解析；获取时刻单独显示。缓存过期以获取时刻判断，不伪造来源时间。

## 阅读与布局

左侧顶部为重点价格及30日成交图，中间为三个4h排行榜，下方为币安警报和GMGN；右侧常驻律动信息流。窄屏在同一页面纵向排列，各列表保留内部滚动。

快讯每15秒读取本机缓存。iframe内容仅在缓存或状态变化时更新，普通时间心跳不重建内容，避免行情刷新使阅读位置反复跳回。会话内还记录当前可见快讯ID及偏移，5分钟数据更新或页面重新加载后按同一快讯恢复位置；若该快讯已超出最新100条才回到顶部。默认12像素/秒上滑，读到底循环；悬停、键盘阅读、手动滚动30秒或展开长文时暂停。可按钮暂停/继续，会话内保留按钮状态；尊重系统减少动画偏好，可手动开启。速度和默认行为可在设置页调整。

正文经HTMLParser去掉标签、脚本和样式，前端仅用textContent填入，JSON转义小于号避免脚本闭合注入。链接只允许官方theblockbeats.info/theblockbeats.news域及其子域，统一HTTPS；不自动加载新闻远程图片或脚本。原文链接新开标签页，保留来源。长内容可在当前页面展开。

## 数据采集与验证

新增`modules.blockbeats_news`版本1，含最新100条纯文本快讯、发布/观测时间和采集状态；健康模块增加律动心跳。原模块合同保留。SFTP外发的暂停状态独立保存，新增快讯不会恢复发送。

测试使用临时数据库和假HTTP响应，覆盖5分钟间隔及重启、去重与修订、失败保留、退避、分页上限、恶意HTML/链接、iframe内容稳定和密钥不进入导出。实际页面另核对滚动、暂停、继续和响应式布局。
