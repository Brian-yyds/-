# 律动中文快讯

使用[官方文档](https://www.theblockbeats.info/apiDoc)的Pro HTTPS接口 `https://api-pro.theblockbeats.info/v1/newsflash`，密钥仅放`api-key`请求头，不放URL。参数`page=1,size=50,lang=cn`，不限制分类，拒绝跟随重定向。

## 调用额度

按用户提供的每月10,000次计划，每285秒（4分45秒）采集一轮：连续31天通常最多9,398次首屏请求，留602次应对重试、补页。正常网页刷新仅读本机缓存，不消耗接口额度。

每次实际发起请求前，SQLite事务预留一次计数，成功、失败、分页都计入；近31天最多9,800次，达到上限等待最早计数到期，期间显示缓存。滚动31天上限比按自然月简单清零更保守；分页较多时会提前暂停，优先保留额度。重启不清零。普通失败至少间隔285秒，鉴权错误等30分钟，429尊重较长的Retry-After。

这只是本机用量保护，不代表服务商剩余额度。接口未返回余额/重置时间响应头，官网当前未登录，实际套餐和剩余额度尚未核实。计数从本版本启用，升级前或其他客户端的调用不包含在内；若这些用量较多，仍需登录官网核对余额。

## 密钥与运行

Windows用当前用户DPAPI加密保存到`user_data/api_keys.blockbeats.dpapi`；其他机器用`BLOCKBEATS_API_KEY`环境变量，环境变量优先。不回显、不进入源码、GitHub、HTML或数据包。设置页“数据与AI接口”可更新。未配置Key只影响快讯。

`launch.py start`启动六个独立服务，桌面快捷方式不变。尊重持久保存的下一次采集时间，重启不会反复请求。失败保留缓存，明确标为重试或过期。

首次读取50条，以后按ID去重及更新修订；离线补齐最多三页/150条，超过上限标记历史可能缺口。缓存保留最近两天观测到的最多500条，页面及数据包含最新100条。发布时间保留来源字符串，无时区日期按北京时间解析；获取时间单独显示。

## 阅读与布局

左侧加宽快讯栏随窗口高度铺满；右侧重点价格、30日图、三个4h榜及两类警报随窗口高度拉长，减少底部留白。顶部导航收在右上角菜单，设置页有返回入口。窄屏在同页纵向排列，各列表内部滚动。

默认只显示标题和发布时间；标题后的“展开”显示完整正文，“收起”恢复标题列表。当前会话内保留展开状态，不增加API请求。只手动上下滚动，无自动滚动、循环、暂停按钮或速度设置。每15秒读取缓存，普通心跳不重建iframe；会话记录当前快讯ID及偏移，数据更新时恢复位置。在顶部阅读则继续显示最新快讯，锚点已超出最新100条时回到顶部。

正文去掉HTML、脚本和样式，前端仅用textContent填入；JSON转义小于号。链接仅允许官方theblockbeats.info/theblockbeats.news及子域的HTTPS页面，不加载外部新闻图片/脚本。原文新标签页打开，长内容可展开。

## 数据与验证

`modules.blockbeats_news`版本1含100条快讯、来源/观测时间、采集状态与本机预算计数。健康模块保留律动心跳。SFTP仍独立暂停，不因快讯修改恢复外发。

临时数据库和假HTTP测试覆盖285秒调度及重启、去重、失败缓存、退避、补页、安全链接、稳定iframe、密钥隔离、失败也计数、并发限额和31天释放。页面实测左侧布局、手动阅读和响应式尺寸。
