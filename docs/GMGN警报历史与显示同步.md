# GMGN 警报历史与声音同步

## 历史警报

主屏 GMGN、特级、Web3 各显示最新100条，按原始报警时间从新到旧排列；框的尺寸不变，在框内上下滚动查看历史。超过100条只是不显示，不删除原始报警，也不影响特级匹配。GMGN与特级使用用户滚动锚点记忆，忽略DOM刷新产生的自动归零，避免刷新时跳回顶部。报警确认不会隐藏历史，同币同自然日的重复记录仍去重，币股排除口径不变。

取消原“最近3条”的显示上限及已确认报警超过30日的清理。报警历史长期保留；原有首次报警后固定10日跟踪池、每日次数和再次放量条件不变。`gmgn_alarm_history_keep` 数据库触发器阻止旧版清理语句删除历史。已经被旧版本删除的记录不能据此恢复，也不生成历史假数据。

2026-11-10按要求移除历史报警市值100K～1M窗口及其专用补查。主屏警报区保留特级、GMGN、Web3三个框；原始报警记录、GMGN警报的正常市值同步和10日双向匹配保持不变。

15分钟异动榜按本次首报起固定4小时有效，同币在此期间只保留一条，到期从主屏移除。回落、反向、重复触发不延长时间；到期后实时仍满足前20名及15分钟>5%的条件可重新报警。启动时恢复本轮到期时间，页面、采集器重启均不重置4小时窗口，原始记录不因到期被删除。

## 特级卡片的原GMGN来源

特级卡片列出“命中时间”“Web3信号时间”“GMGN原报时间”和跟踪到期时间。跨日期匹配标记为“历史GMGN匹配”。原GMGN记录超出主屏最新100条，仍可参与原10日池匹配，不伪造新的GMGN警报或把旧记录移到今天。

特级卡片的成交额和市值标记为“GMGN记录5m成交”“记录市值”，它们是所引用GMGN历史记录的快照，不能当作特级命中时的实时值。早期版本曾用重复采样覆盖GMGN报警数据，迁移保存的旧记录可能已是最后一次合格采样的快照，无法据此反推出最初触发值。本次不重写旧记录；后续重复合格采样只更新last_seen，报警原始payload不再改写，最新行情和市值继续保存在独立缓存。

## 声音与画面

旧实现中声音每3秒直接读取报警表，主屏GMGN卡片却等待每60秒发布的信号快照；特级匹配命中时只即时更新自己的快照。因此同一报警已入库、声音已触发，GMGN卡片仍可能滞后数十秒。这是本地展示链路的不同步，不能从一次延迟推断服务商限频。

现在主屏每轮刷新直接从同一事务中的本地报警表读取GMGN历史，随原有信号快照一起显示；Web3显示与外部采集周期保持不变。完成本轮完整HTML发送后，音频桥接只接收本轮已显示的GMGN记录，不会独立提前读取下一批报警。新入库报警不再等待每分钟快照。正常可见延迟由页面约3秒刷新及本地计算时间决定，不承诺外部接口发现速度。

播放器规则保持不变：仅新的GMGN报警ID、原始触发时间距当前不超过120秒才可能发声；初次进入、开启开关、旧历史、滚动、行情、市值和last_seen更新不补响。同源多窗口去重仍保留。特级与Web3没有新增音源。

本次仅更新本机。服务器部署、SFTP暂停状态、GMGN筛选阈值及特级双向10日匹配条件均未改变。
