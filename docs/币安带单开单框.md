# 币安带单操作动态

本机左侧信息流顶部用“律动快讯 / 跟单动态”切换；原页面底部的单人小框已移入跟单动态。跟单信息流展示币安近30日收益率前50和收益额前50的公开操作，两榜按组合编号合并；熬鹰资本（5075281354358777856）始终保留。收益双榜保留采集，统一放进“全部动态”，不再显示两个榜单入口。筛选按钮依次为“全部动态、精选、聪明钱、熬鹰资本”，均直接展示操作汇总，不再展示展开名单。精选固定为用户截图12个已核对组合编号的项目，一亏三千里、玺九爺HBJX、Btc星辰等均包含，熬鹰资本姓名标红；同名Btc星辰采用截图收益额匹配的4751838302089254401，排除另一个私密同名项目。姓名打开对应中文带单主页。

操作卡显示带单员姓名、来源／精选标签、标的、开多／开空／平多／平空、北京时间、成交均价和开仓／平仓金额。金额使用该条executedQty（已成交数量）乘以avgPrice（成交均价），以十进制计算并保留两位小数，计价币种随来源quoteAsset显示。它是本次操作的名义成交金额，不是保证金或当前剩余总仓位；开仓包含加仓、平仓包含减仓。旧缓存缺数量时显示“待同步”，按正常轮询补齐，不用零或收益额替代。

操作最新在前，手动上下滚动。每次点击“跟单动态”或全部／精选／聪明钱／熬鹰资本按钮，均回到顶部最新记录（重复点击当前按钮也回顶）。后台刷新仍保持手动阅读锚点，顶部阅读时跟随新记录；不会把上一个范围的底部位置带入新范围。快讯阅读位置单独保留。

读取币安网页使用的公开只读 order-history 接口，不使用登录 Cookie、交易 API Key，也不下单。首次和后续成功请求均读取近7天的最新50条操作，按positionSide和side共同识别：LONG+BUY开多、LONG+SELL平多、SHORT+SELL开空、SHORT+BUY平空；未知方向不猜测。这里是最新记录窗口，不是全部历史订单或完整成交账本；不会读取被隐藏的当前仓位。时间使用 orderUpdateTime（成交更新时刻），价格为 avgPrice（成交均价），可能包含部分成交的后续更新，不能仅凭该记录区分首次建仓和加仓，也不能将减仓直接解释为全部平仓。

榜单使用公开query-list接口，固定30D、DESC、ALL、不隐藏满员、不使用AI推荐。实测单次最多30名，按pageSize=30读取第1和第2页，去重校验后取前50；第二页重复第一页或缺页时保留上次完整榜单并标注异常，不把30名称为50名。榜单每15分钟更新。PRIVATE组合不展示操作，不请求其操作；其他榜单成员只读取匿名公开接口实际返回的记录，空列表不能证明没有仓位。

页面首次打开后启动一个进程内独立后台线程，多标签页及会话共享一个线程。原单人线程会退出，避免重复查询。全体操作串行分批请求，请求之间至少等待1秒，不并发轰炸接口；每个榜单成员目标至少间隔120秒，熬鹰资本保持30秒目标。实际刷新间隔还取决于人数、网络耗时及限频，人数增加或资料核验时一轮可能超过数分钟，页面显示每条记录实际采集时间；不能承诺所有人30秒刷新。界面每15秒只读取内存缓存，不等待外部请求。切换快讯和跟单不会额外调用新闻API，律动仍15分钟采集一次。

近7日每人最新50条可见记录缓存在独立user_data/copy_feed.sqlite，重启恢复数据和限频冷却。浏览器合并显示最新500条公开操作，另保留精选及已核验聪明钱各人的最多50条窗口，避免上千条同时渲染。榜单退出者不再参与当前信息流，但这不是完整成交账本，也不作完整性保证。

失败保留上次记录并显示延迟；普通失败独立退避60秒到30分钟，401/403/418/429暂停整个跟单采集至少15分钟，并尊重数字型Retry-After。成功返回空列表才清空该带单员展示。公开网页接口未提供稳定性和披露延迟承诺；本功能不发声，不加入特级匹配或对外上传，也未部署到远端服务器。关闭标签页后线程随网页服务继续运行；网页服务停止后该采集停止，重新打开面板时恢复。


## 聪明钱公开核验

与截图一致，以币安聪明钱近1年盈亏降序、onlyShowSharingPosition=true 查询前100个公开候选（5页，每页20）。目录每小时更新，资料逐个串行核验；与已有订单轮询交替执行，不在页面刷新时发请求。目录失败保留完整旧名单，重复分页不接受，访问限制退避至少15分钟。

公开资料必须 enable、sharingPosition、sharingLatestRecord 均为 true；私密仓位或隐藏操作不采集。Smart Money topTraderId 与跟单 leadPortfolioId 是两个不同的编号，绝不按名字猜测映射，只接受该公开资料明确返回的 futuresCopyTradePortfolioId。关联项目必须实际成功返回开仓记录，才进入聪明钱追踪名单，按原盈亏顺序取最多50人；目录人数、可读人数与授权限制如实显示。开平仓数据仍来自公开跟单操作，不声称是完整聪明钱订单。

2026-11-10实测，聪明钱榜单与资料允许匿名读取，但其 query-order-history 是 private 接口，未登录返回401“Please log in first”。程序不调用该私有接口、不读取Cookie，不用私密交易员凑足50。没有公开关联项目者显示“最新操作需登录授权”，无法展示其开仓。已验证关联项目会自动合并全部动态，精选重叠者只展示一条操作。
