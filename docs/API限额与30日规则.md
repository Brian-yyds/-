# API限额与额外规则核对（2026-11-09）

## 当前请求节奏

GMGN四链每60秒扫描一轮，排行通常每链1页，最多2页；详情最多每轮20个代币。一次详情批量里仍逐个调用接口，不能把一个批次误算成一次HTTP请求。实际观测最近一轮4次排行、20次详情，共24次HTTP请求。两页全满的上界为8次排行加20次详情，即28次/分钟。

[GMGN官方说明](https://github.com/GMGNAI/gmgn-skills/blob/main/docs/cli-usage.md)采用套餐漏桶限频：Free每秒补充5个权重、容量5；Plus为20/20，Pro为50/50。排行一次权重3，代币详情一次权重1，因此典型轮次32权重/分钟、两页上界44权重/分钟。应用中请求间隔至少1.1秒，避免集中突发。当前账号具体套餐与月度剩余额度没有经过服务商余额接口确认，不宣称无限调用。

429或RATE_LIMIT会按服务商reset时间全局冷却，禁止冷却中继续重试。其他单链网络错误独立退避。检查时四链均有成功采集记录，无正在生效的全局限流冷却；旧TLS错误不能误报成配额耗尽。

Web3公开信号按SOL/BSC每链每60秒获取，通常2次HTTP请求/分钟，需要补页时最多4次。公开资料未确认该具体信号接口的数字限额或月度额度；不套用币安现货或合约行情的请求权重。当前未见正在发生的限流，429保留缓存并延后重试。页面读取本机快照不消耗这些API次数。

## 额外规则：已启用（2026-11-09调整）

非北京时间今天毕业、毕业后30×24小时内的发射台代币，5分钟美元成交额严格大于300K，KOL人数严格大于3（至少4人）时报警。边界300K、3人均不通过；聪明钱人数不能替代此分支的KOL条件。继续排除币股/ETF，不把创建时间当毕业时间，缺少毕业时间、外盘状态、成交额或KOL数据时不通过。

此前额外分支因北京时间零点K线未验证而暂停。用户本次将条件改为成交额与KOL，不再要求当日涨幅，因此直接复用已有的外盘开放时间open_timestamp、5分钟成交额、renowned_count，不新增K线或详情调用。四链候选分页也考虑此分支的300K门槛，覆盖不足仍明确标记，不宣称全链穷尽。

今日毕业200K、非发射台100万美元和原KOL或聪明钱至少1人的条件保持不变。原已报警毕业币10日内的跟踪复报分支也保留；符合新增分支时注明“近30日毕业放量”。同币每日一次与成交额连续回落5分钟后再突破的去重继续共用；10日跟踪到期不延长，但未超30日的代币仍可在满足新分支且重新突破时报警。人数波动、重启、确认都不重置成交额去重。

gmgn_extra_30d_rule持久保存新规则，导出包含kol_gt=3，不再包含旧day_change_pct条件。特级警报复用同一判定，与新鲜有效的同链同CA钱包信号交集匹配。SFTP保持暂停。
