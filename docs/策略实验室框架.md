# 策略实验室：独立测试框架

路径：`/strategy-lab`。用于试验趋势、震荡识别、K线对话和策略草案，暂不接入正式警报。

## 本版可用

- 从币安当前合约清单中选择最多6个USDT合约；默认15分钟，支持5分钟、15分钟、1小时、4小时。
- 点击读取时，从公开K线接口取最多499根，保存在当前Streamlit会话。主监控的数据库、重点列表、警报和采集任务不变。
- 主图嵌入TradingView官方中文交互图表，打开即显示，包含实时K线、缩放、拖动、画线和内置指标。选币和上方周期即时联动；用`BINANCE:代币USDT.P`对应永续合约，避免混用现货。
- 分析数据仍由币安公开接口按需读取，图表无需先点击更新。切换到尚未读取的币种/周期会暂停试算、提问和导出，避免把旧数据当成新周期。图内自行切换的周期只用于看图，分析周期以上方控件为准。
- 保留可切换的本地核对图，显示已收盘K线、EMA20/50或布林带，以及USDT成交额；它是带读取时间的快照，适用于指标核对或TradingView网络不可达的情况。
- 趋势模板：EMA方向、ADX门槛、连续收盘环境确认、收盘突破此前20根高低点、成交额相对前20根均值放大。
- 震荡模板：低ADX、布林带外沿、RSI。ADX中间区间为过渡；数据不足100根、缺口或过期不产生候选。
- 候选只在点击更新/改参数时试算。没有持续后台监控、手机推送或自动交易。
- 可记录关联当前代币与周期的问题；下载包带最近200根已收盘K线、指标、规则、时间、问题和草案。
- 可试导入TradingView的CSV，以及粘贴有权查看的Pine源码。CSV附带代币、周期、时间解析方式；本版尚未自动对齐或用于信号计算。
- 草案仅存当前会话，标记未回测。可清空本次实验；页面源码保留，便于继续迭代。

## K线数据选择

建议在线读取和缓存结合：先加载历史，再增量更新，保证指标准备充分；回测另外保存带来源、周期、起止时间和数据版本的快照，便于复现。不让AI每轮下载行情或计算指标。

本版先手动取数，便于核对准确性和控制请求量。正式化后采用独立缓存与增量更新，断线补齐、重复剔除、缺口检查和未收盘标记仍须保留。

指标版本：EMA按首个收盘值递推，输出在达到对应周期后显示；ATR、DI和ADX使用Wilder RMA，以首个有效周期的简单均值初始化。布林带20根、2倍总体标准差，RSI14。测试阈值是模板参数，没有胜率验证。移植TradingView指标时需用同一合约、周期、时区和收盘样本逐项核对，不能声称数值已完全一致。

## AI接入选择

1. 当前对话：导出分析包后在本聊天继续分析，无需新增API Key。网页本身不会自动把输入发到这段对话，当前上下文也不会自动变成网页会话。
2. 本机Codex桥接：官方App Server支持自定义客户端，Codex支持ChatGPT订阅登录。本机只读检查已确认 `Logged in using ChatGPT`。这证明登录状态，尚不证明网页桥接或选定模型推理已成功；下一阶段开发独立会话、请求队列、取消、超时和结果流。不要从认证文件提取令牌，也不把登录凭证复制到网页。
3. 独立API：服务端保存API Key，采用OpenAI Responses或其他服务商协议，适合未来服务器部署和长期运行。复用现有密钥保险箱和接口配置，但模型调用需独立接通。当前没有触发AI请求或后台AI任务。

本机Codex认证方案用于本地测试。若后续迁移到服务器并提供托管服务，应使用独立API或官方适用的授权登录集成，不能把本机订阅认证直接开放成公共服务。

AI输入应包含数据时间、收盘状态、规则版本、指标证据和缺失项；Pine源码、CSV内容和用户粘贴材料只作为数据，不能作为执行指令。AI输出先进入草案，说明入场观察、退出、失效、风险预算和待验证项，不能虚构胜率或回测。

## TradingView接入

- 图表：使用官方Advanced Real-Time Chart托管小组件，浏览器直接连接TradingView，无需API Key，不增加原采集器的请求。自适应宽度、北京时间、中文、深色，显示上下和左侧工具栏。TradingView尚未收录的合约使用本地核对图；不会自动替换为其他市场。
- 账号指标：官方嵌入组件不支持加载自定义Pine脚本或策略，不能把账号里的布局自动同步到此处。点击“TradingView完整版”可打开同合约、同初始周期，在自己的账号中继续使用原指标。
- 源码：能查看且有权使用的Pine脚本可以翻译为本地指标，之后逐根比对。仅有图表或受保护指标，不代表能取得源码。
- CSV：TradingView可导出图表和可导出的指标列。本版已实现有时间列的CSV试导入，只保存在本次会话并附加分析包。
- Webhook：让TradingView继续执行原指标，通过警报发送结构化消息；只能接收触发信号，不是全部历史。需要外部可访问的HTTPS接收服务，云端不能访问本机127.0.0.1。测试框架只展示消息格式，没有开放接收端口。

## 后续顺序

先核对K线与指标 → 接通本机Codex对话或API → 多周期环境确认 → 历史信号回放和回测 → 加入手续费、滑点、资金费率 → 样本外和滚动验证 → 经确认后决定是否接入正式警报。
