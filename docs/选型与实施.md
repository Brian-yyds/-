## 复用与补充

```text
币安公共USDT永续接口
  ├─ Freqtrade下载器 → 本地15m/5m/mark/funding数据
  │    ├─ Freqtrade回测/偏差检测 → FreqUI结果比较
  │    └─ 15m因子格式适配 → Alphalens统计 → 中文研究入口/CSV
  └─ 只读采集适配 → SQLite快照/自选/异动记录 → 中文研究入口
```

不需要改动Freqtrade核心，也不需要新写回测引擎。升级时先在隔离环境验证，再变更版本锁。

## 第一版验收

1. 接口成功时展示真实永续行情；失败/过期可见，不混用现货、不伪装演示行情。
2. 自选15m信号只来自已收盘数据，断档/过期不得触发正常信号。
3. 官方下载器产生本地数据后，原生回测能读取并导出结果。
4. 因子使用下一根开盘标签，跨训练测试边界标签剔除；前缀因子不受未来价格改变影响。
5. 上游统计库直接产生分组与IC；样本不足时拒绝给结果。
6. 仅本机监听、无交易所密钥、无实盘启动，能复现环境与日志。

实际是否满足每条，以验证记录为准，不能将代码存在视为端到端成功。

## 下一阶段

优先级1：真实数据可访问性、资金费完整性、历史退市币池、下载与实验追踪、滚动样本外验证。

优先级2：持仓量/OI与多空比长期归档、盘口流动性与基差因子、成本/换手约束、相关性与行业中性化。

优先级3：常驻服务器部署、访问认证/备份/监控、获得授权后的外部通知。完成这些后再单独评估模拟交易，实盘不在当前范围。
