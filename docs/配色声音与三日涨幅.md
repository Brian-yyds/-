# 暗色配色、声音与三日涨幅

主屏改用灰蓝底色、蓝灰文字和柔和的绿/红，重点数值保留清晰度，避免大面积纯白标题。快讯保持标题折叠及手动阅读；原4h排序、15m警报和GMGN规则不变。

## 三日涨幅

上涨/下跌榜增加近3日价格涨幅，排序仍按滚动4h。OI榜在成交额后补4h价格涨幅及近3日涨幅，OI排序不变。

榜单改为默认可见2条的大字号布局，30条排名仍完整保留，支持鼠标及键盘在框内滚动。主行突出4h涨跌/增仓，底行优先显示成交额，近3日与OI榜4h价格放在辅助区，不再挤入多列表格。默认4h主数值28px，成交额19px，较窄窗口略缩小；下方15m及GMGN警报扩高，报警涨跌24px、GMGN成交额/市值/持有人18px。较矮窗口保留页面滚动，避免为了塞满屏幕再次缩小关键数据。

近3日口径：最新有效价 ÷ 72小时前所在分钟的开盘价 − 1，以百分比显示，分钟取整误差不足60秒。数据来自币安公开`/fapi/v1/klines`的真实1m开盘价，不使用24h字段、日K开盘或小时近似代替。新上市不足72h、目标分钟休市、数据尚未补齐或当前价格过期时显示“—”，不代填零或前一交易日价格。

`price_history.py`在原collector内启动独立线程，共用MarketScanner请求/权重限速和退避；不增加主服务或改变桌面启动器。一次取历史90分钟，缓存未来约89分钟所需的72h基准，避免对每个标的每分钟重复发起请求。先补可见榜单，再覆盖其余全市场；每30秒检查缺失，空结果10分钟后检查、错误至少等60秒。旧缓存按72h窗口清理。首次启动需要分批补齐。

公开数据包的binance_market.rows新增`price_change_3d/base_3d_time/base_3d_price/price_3d_basis`。时间为毫秒，不改变现有`price_change`的4h含义。SFTP仍按用户之前要求暂停。

## 警报声音

右上角“开启GMGN声音”点击后启用，开启不播放测试音。只有新的GMGN警报记录触发一声0.25秒的柔和正弦音。币安15分钟警报、行情、榜单、心跳、重试及已有警报更新一律不响。再次点击静音；刷新或重新进入需再次开启，以“GMGN声音已开”为准。

`sound_ui.py`每3秒仅读本机GMGN警报ID和原始触发时间，候选事件取自页面同一个recent_alerts最近三条；不再查询或发送币安事件。独立v2同源BroadcastChannel隔离旧版混合消息，不新增HTTP接口、不传密钥。稳定播放器不因行情更新重建AudioContext。

首次连接只建立游标、不补播历史，仅新ID且触发不超过120秒的可见GMGN警报发声。会话游标始终取最大值，旧快照倒序到达不能回退重播；静音期间更新游标，重新开启不补播。短时间批量警报合并，至少隔5秒提示一次。相同浏览器同源页面通过localStorage及可用时的Web Locks共享已播放ID，避免多页重响。关闭页面不发声。

## 验证

Python测试覆盖精确分钟基准、跨重启缓存、缺失历史、新上市/休市、无效数值、过期现价及4h排序不变。声音快照测试验证只发送页面GMGN三条记录，last_seen更新不产生新事件。`node tests/test_alert_sound.cjs`隔离执行真实播放器，覆盖开启静默、币安/旧协议不响、旧消息不回退、去重、过期、静音、批量冷却和多页面去重，不写真实警报或发出测试声音。
