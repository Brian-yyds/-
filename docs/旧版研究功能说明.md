# Perp Desk · 币安永续15分钟研究工作台

以成熟开源组件为底座：**Freqtrade + FreqUI + Alphalens Reloaded**。本项目补齐行情扫描、中文入口和研究适配层。

## 已包含

- 全市场在交易的 USDT 保证金永续行情表：24h变化、成交额、标记价格、最新资金费率。
- 最多30个自选：已收盘15m涨跌、相对之前20根成交量的量比；本地异动规则与SQLite日志。
- Freqtrade 官方回测、数据下载、lookahead-analysis、recursive-analysis；FreqUI原生结果比较与图表。
- Alphalens横截面因子检验：动量、反转、波动率、量能、收盘位置；1/4/16根前瞻窗口。
- 按共同区间70/30切分，剔除跨界标签，固定UTC网格抽取不重叠标签；导出样本CSV与摘要JSON。
- 无交易所密钥，默认研究模式、逐仓1倍，不提供实盘启动按钮。

## 打开

在本次工作目录中，右键 `start.ps1` 使用 PowerShell 运行，或在 PowerShell 中执行：

```powershell
.\start.ps1
```

工作台：http://127.0.0.1:8501 。FreqUI：http://127.0.0.1:8080 。

首次配置生成随机的本机FreqUI登录密码，用户名为 `research`。可从工作台侧栏查看，也可读取 `user_data/config.local.json` 的 `api_server.password`。Bot URL填写 `http://127.0.0.1:8080`。

如果迁移到另一台Windows电脑：先安装 Python 3.11+（建议3.12），运行 `setup.ps1`，再运行 `start.ps1`。不需要Docker。运行环境必须可以合法访问币安永续公共接口及Python/GitHub包源。不要共享 `user_data/config.local.json`。

## 第一次使用

1. 打开“市场监控”，核对真实数据更新时间与采集错误。失败时保留空白或明确标记过期，不以模拟行情替代。
2. 在“数据与任务”下载90天15m历史，建议同时选择5m细节数据。官方永续下载器一并处理标记价格和资金费率；下载不等于数据完整，需核对实际覆盖。
3. 固定研究池默认10个：BTC、ETH、SOL、BNB、XRP、DOGE、LINK、ADA、AVAX、SUI。它们是配置示例，不是投资推荐。可在本机配置的 `exchange.pair_whitelist` 修改，使用 `BTC/USDT:USDT` 格式。
4. 因子页先选一个预先定义的假设，运行检验，查看样本内与样本外IC、分组差异及换手。至少10个币、每段20个不重叠横截面才出结果。
5. 回测页提交指定日期区间；结果在FreqUI加载与比较。先样本内，再锁定参数测试样本外；均线基线只验证流程。
6. 比较基础单边费率与提高5/10bps成本情景；再跑未来数据与递归指标检测。未触发交易或样本不足的检测不算“通过”。

## 研究口径

- **信号/标签**：因子使用已收盘K线；在下一根开盘进入，在第h+1根开盘退出。收益是原始价格变化，未计成本。
- **横截面检验**：每个时点在币种之间分五组，由Alphalens计算Spearman Rank IC、分组收益与换手。IC IR仅为均值/标准差，未年化。
- **抽样**：h=4每小时一次、h=16每4小时一次；固定UTC网格避免因缺样本产生标签重叠。样本内标签退出时间必须早于分割点。
- **回测**：采用Freqtrade官方撮合与资金费口径。默认单边手续费5bps是研究假设，须按账户实际费率调整。市场单、止损、K线内路径、滑点和流动性均有模型局限。
- **成本压力**：提高`fee`只是一种额外成本近似，不等同于重建盘口与成交冲击。5m细节回测也不是tick级真实撮合。
- **资金费率**：不设置虚假的0资金费回填。缺失数据应缩短区间或补齐，并核查是否连续。
- **币池**：当前固定现存币种存在幸存者偏差。严肃历史选币需要包含历史退市币并按上市/退市时间构建可交易集合。

## 持续运行

启动器运行时，采集器独立于浏览器，每30秒获取快照；自选K线每15m收盘后更新。异动写本机SQLite，默认不发送外部通知。重复条件按冷却时间记录。

电脑必须保持开机、联网、不休眠，启动器不能关闭。按 Ctrl+C 停止启动器会停止所启动的三个主服务。已提交的下载/回测任务是独立进程，会继续到完成；请先等待任务结束再退出工作台。当前不是系统开机自动启动服务。

也可运行 `stop.ps1` 停止本工作台的主服务；它会核对进程来自当前工作目录，不按端口或模糊进程名停止其他程序。当前会话由助手启动的服务也可以这样停止。

如需24小时运行：下一步迁移到常驻主机，采用systemd或容器进程守护、磁盘备份、断线恢复和健康监控；另行配置获授权的通知渠道。当前没有部署到云服务器，也没有创建定时提醒。

## 常用命令

安装环境后使用其Python运行（例如 `.venv\Scripts\python.exe`；本次环境由 `start.ps1` 自动找到）：

```text
python launch.py download --days 90 --detail
python launch.py backtest --timerange 20260901-20261001 --detail
python launch.py backtest --timerange 20260901-20261001 --fee 0.001
python launch.py lookahead --timerange 20260901-20261001
python launch.py recursive --timerange 20260901-20261001
python -m pytest tests -q
```

时间区间均为UTC，结束日期不包含在内。界面常用时间展示为北京时间。

## 文件

- `app.py`：中文研究入口；`collector.py`：公共行情采集；`research.py`：Alphalens适配。
- `launch.py`：初始化与安全研究命令；`jobs.py`：后台研究任务；`store.py`：本地缓存。
- `config.example.json`：可分享的无密钥模板。
- `user_data/config.local.json`：首次运行生成的本机配置，包含本机登录密码，已忽略。
- `user_data/data/binance/`：Freqtrade下载数据；`backtest_results/`：原生结果；`*.log`：日志。
- `docs/选型与实施.md`：选型依据与下一阶段清单。
- `docs/验证记录.md`：实际验证范围、网络与剩余限制，以此判断是否已跑通。
