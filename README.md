# 市场数据采集与同步

主要作为币安、GMGN及律动的数据采集端，可每分钟通过SFTP向接收服务器发送JSON；本地保留行情、警报和设置页供核对、调试。打开：http://127.0.0.1:8501/ 。

## 当前完整版本（2026-11-13）

仓库同时保存本机完整面板及服务器专用的GMGN、Web3、特级警报版本。服务器核心与本机一致，使用各自独立Key、数据库和配置；SFTP在当前使用中保持暂停，需显式配置才发送。源码不包含任何真实Key、SSH私钥、报警数据库或私人配置，新机器需另行安装依赖和配置凭据。

当前GMGN门槛：今日毕业5分钟成交额>200K且KOL或聪明钱至少1人；非发射台>1M且相同人数条件；30天内非今日毕业>300K且KOL>3。排除币股。特级警报按同链同CA匹配10日事件池，后续成交额回落不撤销已收到的合格事件；按北京时间自然日每天最多一次，跨零点的新Web3信号可重新报警，不是滚动24小时去重。

本机启动见下方说明。服务器源码及保护：[服务器监控保护](docs/服务器监控保护.md)；安装前提与更新：[部署说明](deploy/部署说明.md)；独立Telegram推送源码、服务模板和配置示例：[Telegram部署](deploy/Telegram部署.md)。服务器保护包括30秒独立检查、每小时完整性检查、每日验证备份及7天保留、版本校验和有限恢复。GitHub保存不会自动部署到服务器。

## 页面

- **左侧快讯 / 跟单动态**：顶部按钮随时切换两个手动信息流，保存会话内页签和阅读位置。跟单按币安近30日收益率前50、收益额前50去重采集公开开平仓，收益双榜合并到全部动态；另设截图12位带单员的精选、聪明钱及熬鹰资本独立入口，熬鹰资本标红。聪明钱按近1年盈亏筛查公开前100名，目标接入可读取开仓的前50；最新操作接口需登录，仅通过公开资料明确关联的公开跟单项目接入，显示实际可读人数，不凑足50人；每条显示姓名、榜单名次、标的、操作、北京时间、成交均价、开仓／平仓金额（本笔已成交数量×均价，非当前剩余总仓位）。榜单15分钟更新，操作分批轮询，单人目标120秒（熬鹰30秒），实际耗时和限频可能增加间隔，显示真实采集时间。私密不采集，失败保留缓存，无声音。详见 [带单操作动态](docs/币安带单开单框.md)。

- **律动快讯信息流**：左侧加宽、随窗口高度铺满，默认只显示标题和时间，标题后可展开/收起全文；手动上下阅读，更新保留展开状态及阅读位置。官方Pro中文接口每15分钟获取，连续31天正常2,976次首屏请求，为其他AI保留额度（分页及重试另计）；本机近31天最多9,800次（包含分页和失败请求），达到上限暂停联网、保留缓存。计数从此版本启用，不等于官网余额，历史及其他客户端用量需另计。网页每15秒读取缓存不耗API额度，Key本机加密。详见 [律动快讯](docs/律动快讯.md)。

- **顶部重点监控**：默认BTC、ETH、SOXL，可在“设置与调试”选择最多8个USDT合约。显示最新成交价、滚动近4小时涨跌幅及行情时间，每3秒更新；自动加入重点及行情采集。涨跌优先使用实时采样，缺少样本时采用4小时前所在分钟开盘价，不使用1小时、24小时涨跌或当前4h蜡烛开盘价；行情超过20秒未更新则标为延迟，4小时基准缺失时显示“—”。点击名称打开中文币安合约页，窄屏自动换行。
- **主屏**：左侧快讯与跟单共用瀑布信息流；右侧顶部重点监控，下面依次是特级警报、GMGN、Web3三个并排框，再下面是4小时上涨榜、下跌榜、现有15分钟异动。警报框在常用桌面尺寸加高约25%，每框显示3个代币并留出间距。4小时榜仍默认前2名，保留近3日涨幅和4小时成交额。各框手动滚动，窄屏自动纵向排列。30日成交图、OI榜保持移除。
- **警报历史**：GMGN、特级、Web3各最多显示100条，框内上下滚动。超过100条不显示，GMGN及特级原始历史仍保留；确认或超过30日均不清理GMGN记录。每轮页面刷新直接读本地报警表，显示后再发送同一批记录给声音桥接，消除声音先响、卡片等待分钟快照的问题；Web3采集逻辑不改。详见 [历史与显示同步](docs/GMGN警报历史与显示同步.md)。
- **双源警报**：GMGN和Web3正常每60秒采集，两边每次成功入库立即核对，另有每分钟兜底；页面每3秒读本机缓存。GMGN真实报警进入原10日跟踪池，成交额回落不取消资格；已采集的有效Web3事件保留10日，同链同CA双向匹配，先后顺序不限。命中后永久记录，保留原每日去重，复报不延长跟踪期。正常成交额、人数、币股排除规则不变。详见 [双源与前20监控](docs/Web3与特级警报.md)。
- **15分钟异动**：独立监控24小时USDT成交额前20名（包含BTC和币股/大宗），15分钟内涨跌严格超过5%才产生小警报。同币从本次首报起4小时内只显示一张卡，到期移除；再次满足实时条件可以重新报警，不要求换自然日。同一窗口中反向或反复触发不追加、不延期。保留本次首报时间和基准，当前跟踪涨跌、滚动15分钟涨跌及现价每3秒随行情更新；旧行情显示延迟，不发声。原始报警记录仍保留。
- **额外30日规则**：非今日毕业、毕业后30天内、5分钟成交额严格超过300K且KOL严格大于3（至少4人）时报警，不要求涨幅。今日毕业200K及非发射台100万美元规则不变；币股排除、每日去重与固定10日跟踪不变。接口限额与条件见 [API限额与30日规则](docs/API限额与30日规则.md)。
- **每小时巡检**：启动器自动运行本地健康检查，确认进程退出或心跳停滞后，仅重启对应采集进程，限制重试并记录日志；接口限流、配额和主动暂停不靠重启绕过，不恢复SFTP发送。详见 [自动巡检](docs/自动巡检.md)。
- **警报声音**：右上角开启GMGN声音，只在新的GMGN警报记录出现时响一声。币安15分钟警报、行情/榜单更新、开启按钮和历史记录均不响；游标只增不减，旧消息及重复刷新不重响，多个页面共享已播放记录。再次点击静音，重新加载需重新开启。详见 [配色声音与三日涨幅](docs/配色声音与三日涨幅.md)。
- **GMGN警报市值**：最近3条警报的当前市值每5分钟同步，优先复用行情排行和已有代币详情；不再被榜单覆盖的历史警报才按需补查。仅更新独立市值缓存，不改警报ID和触发时间，不新增警报或响铃；悬停市值可看更新时间，失败保留上次值并提示延迟。
- **GMGN采集恢复**：四链使用50条外盘小批量，榜尾仍可能符合门槛时按成交额边界补查、去重；无法覆盖时明确提示。分链退避重试，主屏显示异常链，调试页可看各链成功时间与错误类别。单链失败保留记录，不重置报警去重；429仍全局暂停。快讯标题使用柔和青灰绿。
- **布局与跳转**：重点监控保持原样，上涨、下跌、15分钟异动三框并排，特级、GMGN、Web3三框并排；窄屏纵向排列。设置仍在右上角菜单。信号卡片保留链、CA、时间和方向，点击查看对应代币。
- **设置与调试**：独立路径 `/settings`，集中管理报警规则、确认报警、顶部代币和重点标的、榜单筛选、GMGN密钥、多个AI接口配置、数据新鲜度及本地GMGN规则试算。保存AI配置不会发起分析；试算不请求行情、不产生真实报警。

## 用法

**设置与调试 → 采集与同步**：定时生成 UTF-8 JSON，通过 SSH 密钥认证的 SFTP 发送给另一台服务器。先上传隐藏临时文件再改名，失败自动重试，重启继续发送；不占用主监控框。默认60秒，可调整。首次需安装专用公钥并核验服务器指纹，才可启用外传。每包包含当前全市场行情、4h榜单、重点报价、币安/GMGN警报、30日成交数据、律动快讯缓存及各来源时间；原始数据库、GMGN/AI密钥、SSH私钥不进入数据包或源码包。详见 [采集同步与接收说明](docs/采集同步与接收说明.md)。

1. 在“设置与调试 → 监控规则”调整GMGN及钱包信号开关。重点监控不变。
2. 监控页查看4小时上涨/下跌、GMGN、Web3及特级警报。币股、ETF和大宗仍参与币安排行榜；GMGN警报仍排除币股。
3. GMGN确认后全部保留的历史仍可滚动查看，原始报警时间不因刷新变更。

## 报警口径

当前规则、双源匹配的新鲜度与去重见 [Web3与特级警报](docs/Web3与特级警报.md)。15分钟警报仅对24小时成交额前20名启用，严格超过5%才触发，旧全市场历史不混入主屏。声音仍仅由新的GMGN报警触发。

## 数据范围

自动扫描币安正在交易的USDT加密资产、币股/ETF及大宗商品永续，保留原有BTC、指数和自定义排除项，数量随交易所更新。股票按币安的EQUITY、HK_EQUITY、KR_EQUITY、CN_EQUITY、PREMARKET分类识别，ETF随股票类纳入；大宗按COMMODITY分类识别，不通过代币名称猜测类别，不自动混入外汇、交割合约或其他结算币种。支持PERPETUAL与TRADIFI_PERPETUAL，股票旁显示“股”、大宗显示“商”。三类资产共用近4小时排行和15分钟急涨/急跌阈值，顶部选币、OI采集、价格推送及历史报警均已恢复。重点及合约类型筛选只改变榜单显示，不影响成交图的独立范围或全市场报警。

休市或暂停时，过期价格不参与实时排行或触发报警；恢复后只使用实际15分钟时间窗口内的参考价格，不将前一交易日的收盘价当作15分钟前的价格。股票OI同样由公开接口分批查询，缺少基准时等待积累，不伪造零变动。

近4小时涨跌优先用目标时间前10秒内的实时价格样本；样本不足时使用4小时前所在分钟的开盘价（实际回看240–241分钟）。OI同样比较4小时前的持仓量，启动使用5m历史快照时以“≈”标记；悬停可查看实际跨度。OI为分批轮询数据，不作瞬时增仓报警。

启动时补齐最多499根1m历史行情及50个5m历史OI快照，分钟K线保留9小时，价格采样保留4小时20分钟。旧版本的1小时窗口设置自动升级为4小时；新币或缺少4小时历史的标的不伪造变动。15分钟价格警报及GMGN的5分钟规则保持独立。

页面每3秒刷新。过期或历史不足的数据不伪造零变化。电脑需保持运行和联网；关闭浏览器仍继续采集，当前提醒显示在本机网页，未配置手机或外部消息推送。

30日成交额由独立`volume_monitor.py`后台从公开`/fapi/v1/klines`小时K线的quote asset volume汇总。首次分段补齐30日历史，每次最多499根小时K线；已有缓存只补缺失时段并刷新最近两个小时，分页缺口不会当成零。每轮完成后等待5分钟，实际间隔还包含扫描耗时。两个线程合计最多约3.3次请求/秒，遵守限流退避，也避让主监控限流。小时缓存保存在`market_hourly_volume`，完整快照为`market_volume_30d`，旧15日快照不再展示或导出。每天先计算各加密合约当日成交额，再汇总全市场及当日前10。仅在全部请求成功且上市时段无缺口时发布，补齐前显示进度，失败保留上次快照。新币上市前不要求历史数据，跨北京时间午夜自动移动30日窗口。

## GMGN 监控

- 初次发现维持四链（SOL / BSC / Base / ROB）5分钟候选扫描。今日毕业分支：北京时间当天毕业、5m美元成交额严格大于150K、KOL大于1（至少2人），不要求聪明钱人数或合计人数。非发射台分支：5m美元成交额严格大于1M、KOL大于1，没有今日限制。继续排除股票/ETF代币。
- 同链同CA每天最多一条报警，按北京时间自然日计算。首次报警起固定10×24小时内跟踪，复报不延长观察窗；到期移出榜单并停止该轮跟踪，旧历史仍保留。已报警毕业代币10日内复报不再要求“今日毕业”，成交额、人数、毕业状态要求仍适用。
- 持续高于门槛不每日重复提醒。成交额连续有效观测5分钟回落至门槛以内，再突破且当日没报过才复报；缺失/断线/离开候选名单和人数波动不重置成交额状态。不要求超过上次报警的成交额。
- 原热搜及成交榜首已删除，左侧替换为10日报警代币榜。按官方代币详情`price.volume_1h`的真实滚动1h美元成交额降序取前10；前5附近可见，内部滚动看其余排名，点击打开对应GMGN页面。只统计真实报警记录的代币，不按创建天数或市值过滤此榜。右侧最近3条报警保留头像、市值及持有人，直接显示原始报警时间（北京时间，YYYY-MM-DD HH:mm:ss）；后续行情更新不改写触发时间，悬停可查看原因。
- 已报警代币按CA继续查询详情，不依赖其仍在热门候选中。每币最短60秒尝试更新，单轮最多20个、按最久未尝试者轮换，批内请求间隔至少1.1秒，轮后另等15秒。接口耗时、池规模及限流会增加实际间隔。超过180秒或缺少小时成交额的数据不进入当前排名；覆盖不全时显示已更新/总数，不能当作全池完整排名。
- 复用官方gmgn-cli 1.6.9的只读SDK、元数据清理及限流处理，固定`https://openapi.gmgn.ai`。只允许5m候选与已验证CA的代币详情查询，不调用交易接口，不加载全局私钥。网页刷新不额外请求GMGN。限频遵守共享冷却；普通单链错误不会阻止其他链和已有报警代币详情更新。
- Windows优先环境变量`GMGN_API_KEY`，否则读取本机DPAPI加密密钥；Linux使用环境变量。新机器安装Node.js及`npm install -g gmgn-cli@1.6.9 --ignore-scripts`，再配置只读Key。已有桌面启动器和每分钟SFTP同步继续使用，GMGN导出模块升为2，包含`watch_ranking`及每日/10日规则，不再导出热搜和成交榜首。

详细口径：[GMGN十日跟踪](docs/GMGN十日跟踪.md)、[币股排除](docs/GMGN币股排除.md)。GMGN社媒瀑布流仍未接入，既有可行性核查见 [社交流接入核查](docs/GMGN社交流接入核查.md)。

## 启动与文件

桌面一键启动：运行一次 `install-desktop.ps1`，桌面会生成“币安异动监控”快捷方式。双击后在后台启动并打开网页；已经启动时直接打开现有页面，不重复启动。关闭网页不会停止监控。以后在当前项目文件夹内更新代码，快捷方式继续有效；如果整体移动文件夹，再运行一次安装脚本。

新电脑先安装 Python 3.11 或更高版本，运行 `setup.ps1` 安装依赖，再安装桌面快捷方式。首次启动日志位于 `user_data/desktop-launcher.log` 和 `user_data/desktop-launcher.error.log`。

启动：`start.ps1`。停止：`stop.ps1`。迁移前先停止服务，再复制`user_data/workbench.sqlite`保存阈值、重点和报警。

- `app.py` / `monitor_ui.py`：监控面板及页面导航；`settings_ui.py`：设置与本地调试页面。
- `live_collector.py`：全市场行情与唯一的15分钟价格报警。
- `market_scanner.py`：全市场历史/OI采集；`monitoring.py`：排行榜计算。
- `gmgn_monitor.py` / `gmgn_bridge.mjs`：独立四链候选采集、每日去重报警与10日小时成交额跟踪；`gmgn_credentials.py`：本机加密密钥。
- `gmgn_tracking.py`：首次报警观察窗、每日报警唯一键、小时详情刷新与前10排行。
- `blockbeats_monitor.py` / `blockbeats_credentials.py`：5分钟律动采集、缓存及本机加密密钥；`blockbeats_ui.py` / `news_feed.html`：独立自动滚动信息流。
- `volume_monitor.py`：独立30日加密市场及每日前10成交额采集、小时缓存与汇总。
- `data_export.py`：版本化的数据合同和模块注册；`export_worker.py`：独立定时打包、持久队列、失败重试；`sftp_sync.py`：专用密钥、服务器指纹校验、SFTP临时上传及改名；`sync_ui.py`：设置页同步入口。
- `store.py`：本机设置、采样与报警记录。
