# 市场数据采集与同步

主要作为币安及GMGN的数据采集端，每分钟通过SFTP向接收服务器发送JSON；本地保留行情、警报和设置页供核对、调试。打开：http://127.0.0.1:8501/ 。

## 页面

- **顶部重点监控**：默认BTC、ETH、SOXL，可在“设置与调试”选择最多8个USDT合约。显示最新成交价、滚动近4小时涨跌幅及行情时间，每3秒更新；自动加入重点及行情采集。涨跌优先使用实时采样，缺少样本时采用4小时前所在分钟开盘价，不使用1小时、24小时涨跌或当前4h蜡烛开盘价；行情超过20秒未更新则标为延迟，4小时基准缺失时显示“—”。点击名称打开中文币安合约页，窄屏自动换行。
- **15日成交双图**：顶部重点价格下方并排展示两个紧凑图：加密全市场每日成交额，以及每日成交额前10个加密合约的合计额。两个图各15根柱，数字统一为亿USDT、保留1位小数；采用相同高度比例，今日未结束的柱用绿色。移除大号期间总额、今日累计和合约数量等汇总文字，采集时间与口径放在悬停提示中；前10图悬停可查看当天的成分。前10每天单独排序，不能拿今天的前10倒推过去。按最近15个北京时间自然日统计，包含今日；以币安K线Quote asset volume计量，不能直接相加不同代币的数量。两图均只包括当前在交易的USDT加密永续（含BTC/ETH），剔除币股、大宗、ETF、盘前、现货、币本位和已下架合约；这些排除只影响成交图。窄窗口自动换行。
- **GMGN 10日报警榜**：第五框左侧为真实报警代币的近1小时美元成交额前10，右侧保留最近3条报警。只跟踪首次报警后10×24小时内的代币，复报不续期，到期剔除；同链同CA按北京时间每天最多报警一次，重启和确认不重置。原热搜、成交榜首及50天/30M筛选已移除。详情见 [GMGN十日跟踪](docs/GMGN十日跟踪.md)。
- **主屏**：OI异动榜、上涨榜、下跌榜统一滚动近4小时统计，成交额列同步使用近4小时USDT成交额；与15分钟急涨急跌报警、GMGN监控五框并排。前三榜默认只露出第1–5名，最多前三十名可在框内滚动查看。五框收窄，下方留空供后续监控使用。
- **报警**：只在15分钟内急涨或急跌达到设定阈值时触发；最新报警也出现在标题行，待确认列表移到第四框内滚动查看，保留标的、方向、变动、时间和触发价。
- **布局与跳转**：顶部切换“监控面板”和“设置与调试”；监控页不放设置表单。字体和间距随宽度调整，较窄窗口自动换行，手机单列；五个框与关键字段均保留。
- **设置与调试**：独立路径 `/settings`，集中管理报警规则、确认报警、顶部代币和重点标的、榜单筛选、GMGN密钥、多个AI接口配置、数据新鲜度及本地GMGN规则试算。保存AI配置不会发起分析；试算不请求行情、不产生真实报警。

## 用法

**设置与调试 → 采集与同步**：定时生成 UTF-8 JSON，通过 SSH 密钥认证的 SFTP 发送给另一台服务器。先上传隐藏临时文件再改名，失败自动重试，重启继续发送；不占用主监控框。默认60秒，可调整。首次需安装专用公钥并核验服务器指纹，才可启用外传。每包包含当前全市场行情、4h榜单、重点报价、币安/GMGN警报、15日双图数据及各来源时间；原始数据库、GMGN/AI密钥、SSH私钥不进入数据包或源码包。详见 [采集同步与接收说明](docs/采集同步与接收说明.md)。

1. 在“设置与调试 → 监控规则”设置急涨/急跌及GMGN阈值并保存。原有阈值会保留，币安初始值各10%。
2. 返回“监控面板”看五个框；主监控包括加密、币股/ETF和大宗合约，排行榜筛选、重点标记不会限制这些市场的报警。只有顶部15日成交双图剔除币股、大宗和ETF；不设置全局屏蔽开关。
3. 在设置页“确认当前报警”收起币安提示。同币同方向多个未确认事件合并显示最新一条，确认时一并处理，原记录仍留在本机；GMGN确认后最近3条历史仍然展示。

## 报警口径

最新价相对过去15分钟内先前低点上涨达到涨幅阈值，或相对先前高点下跌达到跌幅阈值时报警，不等待15分钟收盘。实时行情驱动，推送断开时采用轮询兜底。

币安只保留这一类价格报警。OI仅排行观察，不因一次大幅增仓触发报警，也没有把单次增仓误称为持续缓慢增仓识别。原单项价格/OI/成交额规则、蓄势候选、上行/抛压组合确认已停止生成事件。自动AI、主动成交流和盘口采集也已暂停；已有配置、密钥和记录保留在本机。

同一波持续超阈值只记录一次；波动退回当前阈值95%以下后重新武装。确认不会立即重新触发持续中的同一波，重启保留去重状态。历史1m极值仅使用窗口内完整已收盘分钟作启动参考，不保证捕获每笔成交。

## 数据范围

自动扫描币安正在交易的USDT加密资产、币股/ETF及大宗商品永续，保留原有BTC、指数和自定义排除项，数量随交易所更新。股票按币安的EQUITY、HK_EQUITY、KR_EQUITY、CN_EQUITY、PREMARKET分类识别，ETF随股票类纳入；大宗按COMMODITY分类识别，不通过代币名称猜测类别，不自动混入外汇、交割合约或其他结算币种。支持PERPETUAL与TRADIFI_PERPETUAL，股票旁显示“股”、大宗显示“商”。三类资产共用近4小时排行和15分钟急涨/急跌阈值，顶部选币、OI采集、价格推送及历史报警均已恢复。重点及合约类型筛选只改变榜单显示，不影响成交图的独立范围或全市场报警。

休市或暂停时，过期价格不参与实时排行或触发报警；恢复后只使用实际15分钟时间窗口内的参考价格，不将前一交易日的收盘价当作15分钟前的价格。股票OI同样由公开接口分批查询，缺少基准时等待积累，不伪造零变动。

近4小时涨跌优先用目标时间前10秒内的实时价格样本；样本不足时使用4小时前所在分钟的开盘价（实际回看240–241分钟）。OI同样比较4小时前的持仓量，启动使用5m历史快照时以“≈”标记；悬停可查看实际跨度。OI为分批轮询数据，不作瞬时增仓报警。

启动时补齐最多499根1m历史行情及50个5m历史OI快照，分钟K线保留9小时，价格采样保留4小时20分钟。旧版本的1小时窗口设置自动升级为4小时；新币或缺少4小时历史的标的不伪造变动。15分钟价格警报及GMGN的5分钟规则保持独立。

页面每3秒刷新。过期或历史不足的数据不伪造零变化。电脑需保持运行和联网；关闭浏览器仍继续采集，当前提醒显示在本机网页，未配置手机或外部消息推送。

15日成交额由独立`volume_monitor.py`后台从公开`/fapi/v1/klines`小时K线汇总，首次补齐15日历史（最多499根小时K线），之后读取缺失小时及最近两个小时更新累计额。每轮完成后等待5分钟，实际间隔还包含扫描耗时。两个线程合计最多约3.3次请求/秒，遵守限流退避，也避让主监控的限流等待。小时缓存保存在`market_hourly_volume`，完整快照为`market_volume_15d`；原7日快照不再用于展示。每个交易日先计算各加密合约当日成交额，再分别汇总全市场和当日前10。仅在全部请求成功且已上市时段无缺口时发布，两图共用同一份完整数据；补齐前显示进度，失败保留上次快照，不伪造部分市场总额。新币上市前的时段不计成交额，跨北京时间午夜自动移动15日窗口。

## GMGN 监控

- 初次发现维持四链（SOL / BSC / Base / ROB）5分钟候选扫描。今日毕业分支：北京时间当天毕业、5m美元成交额严格大于200K、KOL大于2、聪明钱与KOL计数合计大于3。非发射台分支：5m美元成交额严格大于1M、KOL大于2，没有今日限制。继续排除股票/ETF代币。
- 同链同CA每天最多一条报警，按北京时间自然日计算。首次报警起固定10×24小时内跟踪，复报不延长观察窗；到期移出榜单并停止该轮跟踪，旧历史仍保留。已报警毕业代币10日内复报不再要求“今日毕业”，成交额、人数、毕业状态要求仍适用。
- 持续高于门槛不每日重复提醒。成交额连续有效观测5分钟回落至门槛以内，再突破且当日没报过才复报；缺失/断线/离开候选名单和人数波动不重置成交额状态。不要求超过上次报警的成交额。
- 原热搜及成交榜首已删除，左侧替换为10日报警代币榜。按官方代币详情`price.volume_1h`的真实滚动1h美元成交额降序取前10；前5附近可见，内部滚动看其余排名，点击打开对应GMGN页面。只统计真实报警记录的代币，不按创建天数或市值过滤此榜。右侧最近3条报警保留头像、市值及持有人；悬停可查看原因和时间。
- 已报警代币按CA继续查询详情，不依赖其仍在热门候选中。每币最短60秒尝试更新，单轮最多20个、按最久未尝试者轮换，批内请求间隔至少1.1秒，轮后另等15秒。接口耗时、池规模及限流会增加实际间隔。超过180秒或缺少小时成交额的数据不进入当前排名；覆盖不全时显示已更新/总数，不能当作全池完整排名。
- 复用官方gmgn-cli 1.6.9的只读SDK、元数据清理及限流处理，固定`https://openapi.gmgn.ai`。只允许5m候选与已验证CA的代币详情查询，不调用交易接口，不加载全局私钥。网页刷新不额外请求GMGN。限频遵守共享冷却；普通单链错误不会阻止其他链和已有报警代币详情更新。
- Windows优先环境变量`GMGN_API_KEY`，否则读取本机DPAPI加密密钥；Linux使用环境变量。新机器安装Node.js及`npm install -g gmgn-cli@1.6.9 --ignore-scripts`，再配置只读Key。已有桌面启动器和每分钟SFTP同步继续使用，GMGN导出模块升为2，包含`watch_ranking`及每日/10日规则，不再导出热搜和成交榜首。

详细口径：[GMGN十日跟踪](docs/GMGN十日跟踪.md)、[币股排除](docs/GMGN币股排除.md)。GMGN社媒瀑布流仍未接入，既有可行性核查见 [社交流接入核查](docs/GMGN社交流接入核查.md)。

## 启动与文件

桌面一键启动：运行一次 `install-desktop.ps1`，桌面会生成“币安异动监控”快捷方式。双击后在后台启动并打开网页；已经启动时直接打开现有页面，不重复启动。关闭网页不会停止监控。以后在当前项目文件夹内更新代码，快捷方式继续有效；如果整体移动文件夹，再运行一次安装脚本。

新电脑先安装 Python 3.11 或更高版本，运行 `setup.ps1` 安装依赖，再安装桌面快捷方式。首次启动日志位于 `user_data/desktop-launcher.log` 和 `user_data/desktop-launcher.error.log`。

启动：`start.ps1`。停止：`stop.ps1`。迁移前先停止服务，再复制`user_data/workbench.sqlite`保存阈值、重点和报警。

- `app.py` / `monitor_ui.py`：监控面板及页面导航；`settings_ui.py`：设置与本地调试页面。
- `live_collector.py`：全市场行情与唯一的15分钟价格报警。
- `market_scanner.py`：全市场历史/OI采集；`monitoring.py`：排行榜计算。
- `gmgn_monitor.py` / `gmgn_bridge.mjs`：独立四链候选采集、每日去重报警与10日小时成交额跟踪；`gmgn_credentials.py`：本机加密密钥。
- `gmgn_tracking.py`：首次报警观察窗、每日报警唯一键、小时详情刷新与前10排行。
- `volume_monitor.py`：独立15日加密市场及每日前10成交额采集、小时缓存与汇总。
- `data_export.py`：版本化的数据合同和模块注册；`export_worker.py`：独立定时打包、持久队列、失败重试；`sftp_sync.py`：专用密钥、服务器指纹校验、SFTP临时上传及改名；`sync_ui.py`：设置页同步入口。
- `store.py`：本机设置、采样与报警记录。

旧版扩展功能的源码仍保留，默认启动不加载AI/盘口/订单流/组合规则。旧版说明见`docs/扩展版说明（已暂停）.md`，不代表当前页面功能。
