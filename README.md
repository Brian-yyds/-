# 全市场异动监控 · 报警专用版

当前页面仅保留三个排行榜与15分钟急涨/急跌报警。打开：http://127.0.0.1:8501/ 。

## 页面

- **主屏**：OI异动榜、上涨榜、下跌榜并排放在首屏，统一近1小时排行。每榜前三十名，榜内滚动。
- **报警**：只在15分钟内急涨或急跌达到设定阈值时触发；最新报警也出现在标题行，待确认列表在三个榜下方。
- **侧边栏**：上涨/下跌阈值、应用阈值、确认报警、全市场/仅重点、币种搜索、OI方向、重点币种编辑。
- 无K线、全市场明细、组合线索、主动成交差、状态页、AI设置或历史记录页。

## 用法

1. 在侧边栏分别设置“急涨达到%”和“急跌达到%”，点击“应用报警阈值”。原有阈值会保留，初始值各10%。
2. 看三个榜和急变报警即可；排行榜筛选、重点标记不会限制全市场报警。
3. 收到报警后，点击侧边栏“确认当前报警”收起提示。同币同方向多个未确认事件合并显示最新一条，确认时一并处理，原记录仍留在本机。

## 报警口径

最新价相对过去15分钟内先前低点上涨达到涨幅阈值，或相对先前高点下跌达到跌幅阈值时报警，不等待15分钟收盘。实时行情驱动，推送断开时采用轮询兜底。

只保留这一类价格报警。OI仅排行观察，不因一次大幅增仓触发报警，也没有把单次增仓误称为持续缓慢增仓识别。原单项价格/OI/成交额规则、蓄势候选、上行/抛压组合确认已停止生成事件。自动AI、主动成交流和盘口采集也已暂停；已有配置、密钥和记录保留在本机。

同一波持续超阈值只记录一次；波动退回当前阈值95%以下后重新武装。确认不会立即重新触发持续中的同一波，重启保留去重状态。历史1m极值仅使用窗口内完整已收盘分钟作启动参考，不保证捕获每笔成交。

## 数据范围

自动扫描币安正在交易的USDT加密资产永续，默认排除BTC、指数和已有排除项，币数随交易所更新。重点标记只改变突出显示和筛选，不缩小全市场监控。

近1小时涨跌优先用目标时间前10秒内的实时价格样本；样本不足时使用1小时前所在分钟的开盘价（实际回看60–61分钟）。OI启动使用5m历史快照时以“≈”标记；悬停可查看实际跨度。OI为分批轮询数据，不作瞬时增仓报警。

页面每3秒刷新。过期或历史不足的数据不伪造零变化。电脑需保持运行和联网；关闭浏览器仍继续采集，当前提醒显示在本机网页，未配置手机或外部消息推送。

## 启动与文件

启动：`start.ps1`。停止：`stop.ps1`。迁移前先停止服务，再复制`user_data/workbench.sqlite`保存阈值、重点和报警。

- `app.py` / `monitor_ui.py`：报警专用页面。
- `live_collector.py`：全市场行情与唯一的15分钟价格报警。
- `market_scanner.py`：全市场历史/OI采集；`monitoring.py`：排行榜计算。
- `store.py`：本机设置、采样与报警记录。

旧版扩展功能的源码仍保留，默认启动不加载AI/盘口/订单流/组合规则。旧版说明见`docs/扩展版说明（已暂停）.md`，不代表当前页面功能。
